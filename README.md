# Hazrie God Mode

My personal Lethal Company cheat mod.

### Features
- **God Mode** - No damage, no death
- **Infinite Sprint**
- **F - Head Light** - Spot light from camera that burns enemies + kills undyable enemies
- **T - Teleport to Ship** - Instant teleport back to ship, drones follow
- **P - Telekinesis** - Smooth levitate animation: item slowly rises 1.6m then spins and hovers in front of you. Press P again to drop. 20m range.
- **K / L - Drone Sentries** - Turn levitated item into left/right sentry. Sentries wander around you and auto-ram enemies for 60 damage. Press K/L again to drop.

### Controls
| Key | Action |
|-----|--------|
| F | Toggle head flashlight |
| T | Teleport to ship |
| P | Levitate / drop item |
| K | Make left drone / drop left drone |
| L | Make right drone / drop right drone |

### Install
1. Install BepInEx 5.4.21
2. Drop `HazrieGodMode.dll` into `BepInEx/plugins`
